# Windenergie-Praktikum auf Basis realer Messdaten

Dieses Repository enthält das im Rahmen der Bachelorarbeit

**„Entwicklung eines Windenergie-Praktikums auf Basis realer Messdaten“**

entwickelte MATLAB-Live-Skript.

Autor: Maximilian Wimmer  
Hochschule München  
Studiengang Sustainable Engineering  
Jahr: 2026

## Inhalt

Das Live-Skript behandelt unter anderem:

- Datenqualität realer Windmessdaten
- Jahres- und Monatsauswertungen
- Windrichtungsverteilung und Windrose
- Leistungskennlinie der Kleinwindkraftanlage
- Zusammenhang zwischen Windgeschwindigkeit, Drehzahl und Leistung
- Schnelllaufzahl und elektrisch abgeleiteten Leistungsbeiwert
- Energieintegration
- Weibull-Verteilung
- idealisierten Höhen- und Rauigkeitseinfluss

## MATLAB-Version

Entwickelt und getestet mit MATLAB R2025b.

## Benötigte Datendateien

Für die vollständige Ausführung werden folgende Messdatendateien benötigt:

- Wind_Mittel-2018.csv
- Wind_Mittel-2017.csv
- Wind_Momentan-2013.csv

Die Messdaten sind nicht Bestandteil dieses Repositorys.
